# AI System Monitor

An AI-powered system monitoring and incident assistant built with Python.

## Goal

The application monitors system resources such as CPU, memory, disk,
network activity, and running processes.

An AI agent will later be able to use these monitoring tools to
investigate system issues and provide explanations to users.

## Planned Features

- System resource monitoring
- Process monitoring
- REST APIs using FastAPI
- GitHub API integration
- AI agent with tool calling
- Historical monitoring data
- Automated testing
- Docker
- CI/CD

## Tech Stack

- Python
- FastAPI
- SQLite
- HTML/CSS/JavaScript
- OpenAI API
- GitHub API
- Docker
- GitHub Actions
